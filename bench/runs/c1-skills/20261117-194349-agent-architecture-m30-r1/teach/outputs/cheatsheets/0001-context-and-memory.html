Where information lives

PlaceLastsPut here
System promptRe-sent every callShort, fixed rules
Messages listOne sessionThe chat and tool results so far
Saved store / notesAll sessionsPer-student facts; load only what is needed
Retrieval storeAll sessionsLong fixed manuals, chunked with machine and heading
ToolFetched on demandLive data such as the calendar

Rules of thumb

  • The model sees only the current window; nothing else exists for it.
  • The whole list is re-sent each call: cost is roughly steps times window size.
  • Nothing survives a session unless the program saves and reloads it.
  • Cheapest token: the one never put in the window.
