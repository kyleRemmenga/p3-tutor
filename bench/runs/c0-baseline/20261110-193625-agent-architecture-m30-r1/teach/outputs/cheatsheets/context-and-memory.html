Rules of thumb

  • The model sees only its context; the program decides what goes in.
  • Total input over a run grows faster than the number of steps, because each call resends the history.
  • Bigger window: delays the hard limit, not context rot, and not the bill.
  • Fixes for a full window: clear old tool results, compact (summarize and restart), use a sub-agent.
  • Nothing survives a session unless saved outside the window and loaded back.
  • Retrieval quality caps answer quality: test the search on real questions first.

Sorting questions

Needed on nearly every call? Always in context. Depends on the student or must outlast the session? Saved notes. Long and needed only sometimes? Retrieve on demand.
