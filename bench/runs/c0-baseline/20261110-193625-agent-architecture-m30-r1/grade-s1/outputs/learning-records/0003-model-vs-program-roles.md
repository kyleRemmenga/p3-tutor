# Open misconception: the model runs the tools itself, and remembers on its own

On quiz 0001 (submission s1), Riley believed the model opens the booking system and runs all three tools inside one call (M4), and that it remembers earlier sessions by itself (M3).
Riley does know the loop's shape and that the model chooses tools from their descriptions.
The next lessons should separate what the model writes from what the program does, and make clear that each model call starts fresh, which is the reason memory has to be built.

**Evidence:** quiz 0001, submission s1, items q2, q4 and q6 (q1 and q3 correct, q5 half right).

**Implications:** Teach context and memory by contrasting what the model sees in each call with what the program saves. Check M4 again with a tracing exercise.
