# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering, Sep 2025)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context, context rot, compaction, note-taking, just-in-time retrieval and sub-agents. Use for: anything on context and memory design.
- [Docs: Memory tool (Claude Platform)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool)
  Official description of a client-side file memory tool, with security cautions. Use for: how persistent notes are wired into an agent.
- [Article: "LLM Powered Autonomous Agents" by Lilian Weng](https://lilianweng.github.io/posts/2023-06-23-agent/)
  Expert survey of agent parts, including short- and long-term memory and vector-store retrieval. Use for: background on memory types.
