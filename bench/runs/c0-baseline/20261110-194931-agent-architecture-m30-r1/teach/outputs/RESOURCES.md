# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Defines context, why more tokens is not always better, just-in-time retrieval with tools. Use for: what belongs in an agent's context and how to manage it.
- [Article: "Managing context on the platform" (Anthropic)](https://www.anthropic.com/news/context-management)
  Announces context editing and a file-based memory tool. Use for: examples of clearing stale tool results and storing memory outside the window.
- [Paper: "Searching for Best Practices in Retrieval-Augmented Generation" (arXiv)](https://arxiv.org/pdf/2407.01219)
  Research comparison of RAG design choices, including chunking and embeddings. Use for: choosing how to index and search the manuals.
